# My Blog Website

This project is a simple personal blog website with an admin area where the owner can add, edit, and delete posts.

## How to run on a laptop

1. Copy this whole folder to the laptop.
2. Double-click start.bat.
3. The website will open in the browser.
4. Go to the admin page to log in and publish blog posts.

## Notes

- The website stores posts in the browser local storage.
- This means it works well for one computer and one owner using that laptop.
- If you want to make it available online for everyone, it will need a backend and online hosting.

## Files

- index.html = home page
- admin.html = admin login and manage posts
- post.html = single blog article page
- app.js = website logic
- style.css = styling
